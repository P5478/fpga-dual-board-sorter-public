# 02 · 硬件平台与选型

## 1. 主控：安路 PH1P35

| 项目 | 参数 |
|---|---|
| 器件 | 安路科技 PH1P35（封装 PH1P35MDG324） |
| 开发工具 | Anlogic TD |
| 特点 | 内置高性能 DSP/BRAM，适合图像流水线；国产化平台 |

选它的原因很实际：板卡现成、工具链能用、资源足够做 720p 实时处理。
两块板使用同一型号，调试经验和代码可以互相复用。

## 2. 板 1（视觉板）

| 外设 | 说明 |
|---|---|
| MIPI 摄像头 | SC500CS 传感器，1280×720，RAW10 输出 |
| 摄像头控制 | SCCB（类似 I2C）配置寄存器；24MHz 主时钟 |
| HDMI 输出 | 用于本地监视（TMDS 差分） |
| 千兆以太网 | RGMII 接口，PHY 硬连固定引脚 |
| 按键 ×4 | 分别用于自动白平衡、自动曝光、检测档位切换等 |
| 八位数码管 | 显示当前静态目标数量 |
| USB 调试串口 | 帧统计、状态输出 |

摄像头链路：

```mermaid
flowchart LR
    S[SC500CS 传感器] -->|MIPI 2 lane| R[MIPI 接收]
    R --> U[RAW10 解包]
    U --> D[去马赛克]
    D --> RGB[RGB888]
    RGB --> AE[自动曝光/白平衡]
```

## 3. 板 2（显示 + 机械臂板）

| 外设 | 说明 |
|---|---|
| 千兆以太网 | 与板 1 同型号 PHY |
| HDMI 输出 | 1280×720，显示处理后的画面 |
| 20 脚扩展口 | 全部并联驱动总线舵机（只发不收） |
| 舵机回读输入 | 接总线舵机的 TXD，用于位置回读 |
| 按键 ×4 | 复位 / 启动 / 特效 / 分拣模式 |
| 拨码 ×4 | 手势显示开关 / L 区巡航 / R 区巡航 / 泄力标定 |
| 八位数码管 | 显示当前分拣模式（颜色/形状） |
| USB 调试串口 | 帧统计 + 机械臂状态 + 舵机指令原文 |

> 说明：板 2 顶层还保留了摄像头相关的端口和模块（由底板参考设计继承而来），
> 当前系统里不使用——板 2 的画面全部来自以太网。

## 4. 机械臂

- **结构**：五自由度，末端为吸盘（气泵）。
- **驱动**：5 个串行总线舵机，一条总线级联，每只舵机有独立 ID。

| 舵机 ID | 关节 |
|---|---|
| #000 | 底座旋转 |
| #001 | 大臂抬升 |
| #002 | 小臂伸缩 |
| #003 | 腕部摆动 |
| #004 | 末端转向 |

总线舵机的优点：一根信号线串起 5 个舵机，每个都有唯一 ID，
可以直接给某个舵机发"走到某位置、用多长时间"的指令，还能回读当前位置。
缺点：总线上所有舵机共享带宽，指令要排队，时序设计要留余量。

## 5. 桌面布局

```
        ┌──────────── 画面 ────────────┐
        │   L1       L3       L5       │   ← 下排（远）
        │   L2       L4       L6       │   ← 上排（近）
        └──────────────────────────────┘
                     ▲ 摄像头俯视

        L 区（取件）                R 区（落点）
        ┌──┬──┬──┐                 R1  R2  R3
        │L1│L3│L5│                 R4  R5  R6
        ├──┼──┼──┤
        │L2│L4│L6│
        └──┴──┴──┘
```

- **L 区**：3 列 × 2 行共 6 格，待分拣的积木放在这里。
- **R 区**：6 个落点，按分拣规则把积木送过去。

## 6. 电源与安全

- 5 个舵机同时动作电流较大，总线电源需要留足余量；
- 固件里对舵机位置做了软件限幅，避免机械结构撞限位；
- 提供"泄力"模式：舵机断开输出，可以用手直接摆动手臂做标定。
