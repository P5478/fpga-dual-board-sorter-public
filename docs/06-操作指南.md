# 06 · 操作指南

## 1. 开机顺序

1. 连接摄像头、HDMI、网线（板 1 ↔ 板 2）、机械臂总线、舵机电源。
2. 先给板 1 上电：摄像头开始出图，板 1 数码管显示目标数量。
3. 再给板 2 上电：屏幕出现画面，说明以太网链路正常。
4. 最后给舵机电源上电（避免上电瞬间机械臂乱动）。

## 2. 板 1 按键

| 按键 | 功能 |
|---|---|
| K1 | 自动白平衡开关 |
| K2 | 自动曝光开关 |
| K3 | 未使用（显示特效在板 2） |
| K4 | 检测档位循环切换：原图 → 运动检测 → 静态彩色多目标 → 掩膜 |

档位说明：

- **原图**：不叠加任何检测框，适合观察画质。
- **运动检测**：帧差法，动的目标会被框住。
- **静态彩色多目标**：识别静止的彩色积木——**机械臂分拣必须用这一档**。
- **掩膜**：黑底白目标，用于观察识别模块看到的二值化结果。

## 3. 板 2 按键与拨码

### 按键

| 按键 | 功能 |
|---|---|
| K1 | 机械臂复位（松开后自动回初始位） |
| K2 | 启动：跑一趟分拣 |
| K3 | 显示特效切换（19 档循环，最后一档是快照模式） |
| K4 | 分拣模式切换：按颜色 ↔ 按形状（数码管显示 1=颜色 2=形状） |

### 拨码

| 拨码 | 功能 |
|---|---|
| SW1 | 手势行显示开关：拨到接地一侧显示 `FINGERS: N`，拨回隐藏 |
| SW2 | L 区落点巡航：自动走访 L1~L6，每格压一下再抬起 |
| SW3 | R 区落点巡航：自动走访 R1~R6 |
| SW4 | 舵机泄力 + 位置回读（手动标定模式） |

## 4. 跑一次分拣

1. **板 1 K4 切到"静态彩色多目标"档**（关键！其它档不会输出格子标签）。
2. 把积木摆进 L 区 6 个格子，屏幕上的识别框应该稳定套住每块积木。
3. 板 2 用 K4 选分拣模式（颜色或形状），数码管确认。
4. 按一下 K2：机械臂开始逐格搬运。
5. 搬完后自动回初始位。如果画面里还有遗漏，可以再按一次 K2。

> 提示：按 K2 前确认机械臂活动范围内没有人手和杂物。

## 5. 标定流程

### 5.1 标定格子位置（板 1）

1. 板 1 K4 切到静态彩色多目标档，把积木依次放进 6 个格子。
2. 观察屏幕上的识别框是否落在对应格子里。
3. 如果整体偏移，需要调整格子标定参数并重新烧录（参数在私有工程里）。

### 5.2 标定机械臂落点（板 2）

1. 拨 SW4 进入泄力模式：舵机松开，可以用手自由摆动手臂。
2. 把吸盘摆到目标落点上方，串口会周期打印 5 个舵机的当前位置。
3. 记录数值，更新动作表后重新烧录。
4. 拨回 SW4 退出泄力，按 K1 回初始位验证。

### 5.3 落点核对

- 拨 SW2：机械臂自动走访 L 区 6 个落点；
- 拨 SW3：自动走访 R 区 6 个落点；
- 观察吸盘是否对准格子中心，偏差大就回到 5.2 重新标定。

## 6. 调试接口

板 2 的 USB 串口（115200 8N1）上同时挂着三路信息（按空闲电平相与合并）：

| 开头 | 内容 |
|---|---|
| `F..` / `M..` / `L..` | 帧统计：收到的帧数、行数、丢帧数 |
| `=oi:stepY ...` | 机械臂状态行：当前格号、步骤号、6 格标签 |
| `#...!` | 发给舵机的原始指令 |

板 1 的调试串口输出识别统计信息。

## 7. 常见问题

| 现象 | 可能原因 |
|---|---|
| 屏幕黑屏 | 板 1 没出图 / 网线没插好 / 板 2 没收到帧 |
| 画面撕裂或横向错位 | 以太网丢帧，检查网线和 PHY 状态 |
| 按 K2 机械臂不动 | 板 1 K4 不在静态彩色档（没有标签）；或机械臂正处于泄力模式 |
| 机械臂搬错格 | 格子标定偏移，或标签去抖时间不够（画面抖动大） |
| 舵机有个别动作没执行 | 步骤等待余量不足，需要调大速度系数 |
| 手势数量跳变 | 光照变化大，尽量在稳定光源下使用 |
